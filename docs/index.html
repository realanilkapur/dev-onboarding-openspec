Download the script

Windows

Open PowerShell in an empty folder and run:

Invoke-WebRequest -UseBasicParsing https://github.com/realanilkapur/dev-onboarding-openspec/releases/latest/download/onboard.ps1 -OutFile onboard.ps1
Invoke-WebRequest -UseBasicParsing https://github.com/realanilkapur/dev-onboarding-openspec/releases/latest/download/SHA256SUMS -OutFile SHA256SUMS
macOS and Linux

Open a terminal in an empty folder and run:

curl -fsSLO https://github.com/realanilkapur/dev-onboarding-openspec/releases/latest/download/onboard.sh
curl -fsSLO https://github.com/realanilkapur/dev-onboarding-openspec/releases/latest/download/SHA256SUMS

You can open the script in any text editor and read it before running it.

Check the download

This compares the script with the checksum published with the release.

Windows 
$expected = ((Get-Content SHA256SUMS) -match 'onboard\.ps1$' -split '\s+')[0]
if ((Get-FileHash onboard.ps1 -Algorithm SHA256).Hash -eq $expected) { 'OK: checksum matches' } else { 'STOP: checksum does not match' }

You should see OK: checksum matches. If you see STOP, delete the file and download it again.

macOS 
grep ' onboard.sh$' SHA256SUMS | shasum -a 256 -c -
Linux 
grep ' onboard.sh$' SHA256SUMS | sha256sum -c -

You should see onboard.sh: OK. If not, delete the file and download it again.

Preview what will change

You skipped the checksum check, so this download was not checked.

The preview lists what is already installed and what the script would change. It changes nothing.

Windows 
powershell -NoProfile -ExecutionPolicy Bypass -File .\onboard.ps1 -Agent both -WhatIf
macOS and Linux 
bash onboard.sh --agent both --dry-run

Run the setup

You skipped the checksum check, so this download was not checked.

Windows 
powershell -NoProfile -ExecutionPolicy Bypass -File .\onboard.ps1 -Agent both

Installs for your user account with winget. It never asks for administrator rights.

macOS and Linux 
bash onboard.sh --agent both

Installing packages on Linux needs sudo. The script shows each sudo command and runs it only after you type YES.

The script shows its plan, then stops before each step that changes something and shows what it found and what it will do:

  • Press Enter to run the step.
  • Type S to skip it. Steps that need it are skipped too.
  • Type Q to stop. Nothing after that point changes.

Steps that are already done are listed without stopping. Running the same command again offers anything you skipped.
